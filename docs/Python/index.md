# Python

Chào mừng bạn đến với chuyên mục **Python**.

Đây là nơi mình tổng hợp các kiến thức, hướng dẫn, ví dụ thực tế và dự án liên quan đến lập trình Python.

Nội dung được chia thành nhiều phần, từ những kiến thức nền tảng dành cho người mới bắt đầu đến các chủ đề nâng cao và những dự án thực hành.

## Nội dung

### 🐍 Python cơ bản

Các kiến thức nền tảng cần thiết để bắt đầu học và lập trình với Python.

- Tổng quan về Python
- Cú pháp Python
- Biến, kiểu dữ liệu và toán tử
- Chuỗi
- Kiểu số
- List
- Tuple
- Dictionary
- Câu lệnh điều kiện
- Vòng lặp
- Hàm
- Module và Package
- Làm việc với File
- Lập trình hướng đối tượng
- Virtual Environment

👉 [Học Python cơ bản](/docs/python/python-co-ban)

### 🚀 Python nâng cao

Các kiến thức nâng cao giúp bạn hiểu sâu hơn về Python và xây dựng những chương trình phức tạp hơn.

Phần này sẽ được cập nhật thêm trong quá trình mình học tập và phát triển các dự án thực tế.

👉 [Xem Python nâng cao](/docs/python/python-nang-cao)

## 🎯 Mục tiêu

Mục tiêu của chuyên mục này là xây dựng một hệ thống tài liệu Python dễ đọc, dễ thực hành và có thể sử dụng như một tài liệu tham khảo trong quá trình học tập và phát triển dự án.
