# Python nâng cao

Phần **Python nâng cao** dành cho những bạn đã nắm được các kiến thức cơ bản về Python và muốn tiếp tục tìm hiểu sâu hơn về ngôn ngữ, cách tổ chức chương trình và xây dựng ứng dụng thực tế.

Nội dung tập trung vào việc viết code **hiệu quả, rõ ràng, có tổ chức và dễ mở rộng**.

## Nội dung

### Lập trình hướng đối tượng

Tìm hiểu sâu hơn về cách xây dựng chương trình theo mô hình hướng đối tượng.

Các nội dung có thể bao gồm:

- Class và Object.
- Thuộc tính và phương thức.
- Constructor và Destructor.
- Kế thừa.
- Đóng gói.
- Đa hình.
- Abstract Class.
- Composition.

### Xử lý dữ liệu

Làm việc với dữ liệu theo những cách linh hoạt và hiệu quả hơn.

Các nội dung:

- List Comprehension.
- Dictionary Comprehension.
- Set Comprehension.
- Lambda.
- `map()`.
- `filter()`.
- `reduce()`.
- `zip()`.
- `enumerate()`.

### Xử lý lỗi và Exception

Tìm hiểu cách phát hiện và xử lý các lỗi trong chương trình.

Các nội dung:

- `try`.
- `except`.
- `else`.
- `finally`.
- `raise`.
- Tạo Custom Exception.

### Làm việc với Module và Package

Tìm hiểu cách tổ chức một chương trình Python thành nhiều module và package.

Các nội dung:

- Import module.
- Tạo module riêng.
- Package.
- `__init__.py`.
- Quản lý cấu trúc project.
- Tái sử dụng code.

### Làm việc với File và dữ liệu

Tìm hiểu cách đọc, ghi và xử lý dữ liệu từ các loại file phổ biến.

Các nội dung:

- Text file.
- CSV.
- JSON.
- Encoding.
- Đọc và ghi dữ liệu.
- Xử lý đường dẫn.

### Virtual Environment

Tìm hiểu cách tạo môi trường Python riêng cho từng dự án.

Các nội dung:

- Tạo virtual environment.
- Kích hoạt môi trường.
- Cài đặt package.
- `pip`.
- `requirements.txt`.
- Quản lý dependency.

### Làm việc với thư viện

Tìm hiểu cách sử dụng các thư viện Python để mở rộng khả năng của chương trình.

Quá trình học sẽ tập trung vào:

**Cài đặt → Import → Sử dụng → Đọc tài liệu → Áp dụng vào dự án**

## Mục tiêu

Sau khi hoàn thành phần Python nâng cao, bạn có thể:

- Viết chương trình có cấu trúc tốt hơn.
- Tổ chức project thành module và package.
- Xử lý lỗi trong chương trình.
- Làm việc với nhiều loại dữ liệu.
- Sử dụng thư viện Python.
- Xây dựng các chương trình có quy mô lớn hơn.
- Chuẩn bị kiến thức để bước sang các dự án thực tế.
