# Python cơ bản

Chào mừng bạn đến với phần **Python cơ bản**.

Đây là phần dành cho những bạn mới bắt đầu học Python, tập trung vào những kiến thức nền tảng cần thiết để có thể đọc, hiểu và tự viết các chương trình Python.

## 📚 Nội dung học

### 🐍 Làm quen với Python

Tìm hiểu Python là gì, cách Python hoạt động và những kiến thức đầu tiên khi bắt đầu lập trình.

- Tổng quan về Python
- Cú pháp Python
- Cách viết và chạy chương trình Python

### 🔢 Biến, kiểu dữ liệu và toán tử

Làm quen với cách lưu trữ và xử lý dữ liệu trong Python.

- Biến
- Kiểu dữ liệu
- Toán tử
- Kiểu số
- Chuỗi
- List
- Tuple
- Dictionary

### 🔀 Cấu trúc điều khiển

Học cách điều khiển luồng thực thi của chương trình.

- Câu lệnh `if`
- `if...else`
- `if...elif...else`
- Vòng lặp `for`
- Vòng lặp `while`

### 🛠️ Hàm và Module

Tìm hiểu cách tổ chức và tái sử dụng code.

- Hàm
- Tham số và đối số
- Giá trị trả về
- Module
- Package

### 📄 Làm việc với File

Tìm hiểu cách đọc, ghi và xử lý dữ liệu từ file bằng Python.

### 🏗️ Lập trình hướng đối tượng

Làm quen với những khái niệm cơ bản của OOP trong Python.

- Class
- Object
- Constructor
- Destructor

### 🧪 Môi trường ảo

Tìm hiểu cách tạo và sử dụng **Virtual Environment** để quản lý môi trường và thư viện Python.

## 🎯 Mục tiêu

Sau khi hoàn thành phần Python cơ bản, bạn có thể:

- Hiểu được cú pháp cơ bản của Python.
- Sử dụng các kiểu dữ liệu phổ biến.
- Viết chương trình với điều kiện và vòng lặp.
- Xây dựng và sử dụng hàm.
- Làm việc với List, Tuple và Dictionary.
- Đọc và ghi dữ liệu từ File.
- Hiểu những khái niệm đầu tiên về OOP.
- Biết cách sử dụng Virtual Environment.
